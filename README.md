## AI GIF Generation

*Tools that create GIFs from text prompts, images, or videos using AI.*

- [Moxion](https://moxion.ai) — AI GIF & video platform. Text-to-GIF, image-to-GIF, video-to-GIF with 5 AI models (PixVerse V6, H3 Max, Seedance 2.5, Kling V3 Pro, Veo 3.1). Free tier available.
- [Pika](https://pika.art) — AI video generation, export as GIF.
- [Runway](https://runwayml.com) — AI video editing and generation, supports GIF export.
- [Kaiber](https://kaiber.ai) — AI animation tool, supports GIF output.
- [DeepMotion](https://deepmotion.com) — AI motion capture to animated GIF.

## GIF Editors & Converters

*Online tools for editing, cropping, resizing, converting, and creating GIFs without AI.*

- [EzGIF](https://ezgif.com) — The classic. GIF maker, editor, optimizer, converter. Supports crop, resize, reverse, speed change, text overlay.
- [Moxion GIF Tools](https://moxion.ai/gif-tools) — Browser-side GIF compressor, resizer, cropper, and converter (video/GIF, WebP/GIF). No upload required.
- [ILoveIMG](https://www.iloveimg.com) — Batch GIF crop, resize, compress, convert.
- [GIPHY GIF Maker](https://giphy.com/create/gifmaker) — Create GIFs from images, videos, or URLs. Direct publish to GIPHY.

## GIF Compressors & Optimizers

*Tools that reduce GIF file size, often running entirely in the browser.*

- [Moxion GIF Compressor](https://moxion.ai/gif-compressor) — Browser-based lossy/lossless compression with live preview. Handles files up to 100MB.
- [SquishyFile GIF Compressor](https://squishyfile.com/gif-compressor) — gifsicle ported to the browser via WebAssembly.
- [GIFClear](https://gifclear.com) — Browser-based GIF editor with compression and size targeting.
- [EzGIF Optimizer](https://ezgif.com/optimize) — Lossy GIF optimization with quality slider.

## Platform-Specific GIF Makers

*Tools for making GIFs that meet each platform's size and format rules.*

- [Moxion Discord GIF Maker](https://moxion.ai/discord-gif-maker) — Free Discord emoji, sticker, and server-icon GIF maker. Animated styles include pulse, shimmer, head bob, eye blink, burst laugh. No Nitro required to create.
- [Kapwing Discord GIF Maker](https://www.kapwing.com) — Video/image to GIF, manual sizing for Discord's 256KB emoji limit.
- [Canva GIF Maker](https://www.canva.com) — Template-driven GIF creation for social platforms.
