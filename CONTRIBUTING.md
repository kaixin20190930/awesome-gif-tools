# Contributing

Found a tool that belongs here? Open a pull request.

## Rules

- **Web-based tools only** in the first five sections. Desktop and CLI tools go in the last section.
- **Free tier must actually work** without signup, or be clearly labeled as paid.
- **One line per tool**: `[Tool Name](https://example.com) — What it does in one sentence.`
- No affiliate links.
- Alphabetical order within each section.

## How to add a tool

1. Fork this repo.
2. Add your tool to the right section in `README.md`. One line, alphabetical order.
3. Open a pull request with a short description of the tool.
4. Wait for review. I'll merge or comment within a few days.

## What makes a good submission

- The tool is actively maintained.
- It does something the list doesn't already cover.
- The description is short and descriptive, not marketing copy.

These guidelines are adapted from the [awesome list contribution spec](https://github.com/sindresorhus/awesome/blob/main/contributing.md).
